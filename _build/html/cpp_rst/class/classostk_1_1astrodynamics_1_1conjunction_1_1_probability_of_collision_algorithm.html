    class ProbabilityOfCollisionAlgorithm¶

    Probability of collision algorithm (abstract).

    Base class for algorithms that compute the probability of collision for a close approach.

    The recommended way to use the algorithms is as follows:

    1. List the algorithms to use, in order of preference.

    2. Loop over the list and pick the first algorithm applicable to the close approach (see isApplicable()), then check whether it computes a maximum probability of collision (see isMaximum()).

    3. If the algorithm does not compute a maximum probability of collision, compute the probability of collision analysis (see ComputeProbabilityAnalysis) and check its region:

      • ProbabilityRegion::Robust: use the probability of collision.

      • ProbabilityRegion::Diluted: use the maximum probability of collision as an upper bound.

      • ProbabilityRegion::Unknown: try the next applicable algorithm in the list.

    4. If the algorithm computes a maximum probability of collision, compute the probability of collision (see computeProbabilityOfCollision()) and use it as an upper bound.

    const Array<Shared<const ProbabilityOfCollisionAlgorithm>> algorithms = {
    std::make_shared<Alfano2005>(),
    std::make_shared<Frisbee2015>(),
};

for (const auto& algorithmSPtr : algorithms)
{
    if (!algorithmSPtr->isApplicable(closeApproach))
    {
        continue;
    }

    if (algorithmSPtr->isMaximum())
    {
        // Upper bound
        return algorithmSPtr->computeProbabilityOfCollision(closeApproach, hardBody1SPtr, hardBody2SPtr);
    }

    const ProbabilityOfCollisionAlgorithm::Analysis analysis =
        ProbabilityOfCollisionAlgorithm::ComputeProbabilityAnalysis(
            algorithmSPtr, closeApproach, hardBody1SPtr, hardBody2SPtr
        );

    if (analysis.region == ProbabilityOfCollisionAlgorithm::ProbabilityRegion::Robust)
    {
        return analysis.probabilityOfCollision;
    }

    if (analysis.region == ProbabilityOfCollisionAlgorithm::ProbabilityRegion::Diluted)
    {
        // Upper bound
        return analysis.maximumProbabilityOfCollision.value();
    }

    // ProbabilityRegion::Unknown: try the next algorithm
}

    virtual Array<String> identifyUnsatisfiedAssumptions(const CloseApproach &aCloseApproach) const = 0¶

    Identify unsatisfied assumptions for a close approach.

    Use this before computing the probability of collision if you want to know why the algorithm might not be applicable to a close approach.

    The returned array might be non-exhaustive, as the algorithm implementation might exit early upon encountering an unsatisfied assumption.

    An empty array means that the algorithm is applicable to the close approach.

    Use isApplicable() instead if you only want to know if the algorithm is applicable, but do not necessarily care about the reasons why.

if (unsatisfiedAssumptions.isEmpty())

    static Analysis ComputeProbabilityAnalysis(const Shared<const ProbabilityOfCollisionAlgorithm> &aProbabilityOfCollisionAlgorithmSPtr, const CloseApproach &aCloseApproach, const Shared<const HardBody> &aHardBody1SPtr, const Shared<const HardBody> &aHardBody2SPtr, const bool &scaleObject1Covariance = true, const bool &scaleObject2Covariance = true)¶

    Compute the probability of collision analysis of a close approach using a probability of collision algorithm.

    The analysis is not applicable to algorithms computing a maximum probability of collision (see isMaximum()), as their probability of collision is already an upper bound.

    This function computes the probability of collision and locates the maximum probability of collision as it scales the covariance(s): starting from the unscaled covariance(s), a root solver (bracket and solve) locates where the slope of the probability of collision with respect to the (logarithmic) scaling factor changes sign. The probability of collision is assumed to have a single maximum.

    • If the maximum probability of collision is found to the "right" of the probability of collision (i.e. a scaling factor greater than or equal to 1), then the close approach is in the robust region (ProbabilityRegion::Robust).

    • If the maximum probability of collision is found to the "left" of the probability of collision (i.e. a scaling factor less than 1), then the close approach is in the diluted region (ProbabilityRegion::Diluted).

    • If the root solver does not converge (e.g. the probability of collision does not change with the covariance scaling, or has no maximum), then the region is unknown (ProbabilityRegion::Unknown).

    The scaling factors yielding the maximum probability of collision are also returned, both as a covariance scaling factor and as a sigma scaling factor. In the unknown region (ProbabilityRegion::Unknown), the maximum probability of collision and its scaling factors are empty.

    Raises an Undefined error if the probability of collision algorithm is null, and a RuntimeError if it computes a maximum probability of collision or if neither covariance is to be scaled.

    Alfano, Salvatore. (2020). Relating Position Uncertainty to Maximum Conjunction Probability. The Journal of the Astronautical Sciences. 53. 193-205. 10.1007/BF03546350.
