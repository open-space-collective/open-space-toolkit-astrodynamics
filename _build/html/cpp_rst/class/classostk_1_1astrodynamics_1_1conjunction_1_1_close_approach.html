    class CloseApproach¶

    Close approach between two objects.

    This class represents a close approach event between two objects, providing access to the states of both objects at the time of closest approach, the miss distance, and the relative state. The covariances of both objects, if any, are carried by their respective states.

    Shared<const Frame> computeEncounterFrame(const Shared<const Frame> &aFrameSPtr = Frame::GCRF()) const¶

    Compute the "default" convention of the encounter frame centered on Object 1.

    The encounter frame is a local orbital frame centered on Object 1:

    • z-axis: Normalized relative velocity (Object 2 velocity - Object 1 velocity)

    • y-axis: Normalized cross product of the z-axis and the relative position (Object 2 position - Object 1 position)

    • x-axis: Completes the right-handed coordinate system

    CloseApproach closeApproach = { ... } ;
Shared<const Frame> encounterFrame = closeApproach.computeEncounterFrame() ;
    Parameters:

    aFrameSPtr -- The inertial (or quasi-inertial) frame in which relative position and velocity are computed. Defaults to GCRF.

    Returns:

    The encounter frame

    RotatedEncounterFrameParameters computeRotatedEncounterFrameParameters(const Shared<const Frame> &anEncounterFrameSPtr, const bool &xAlongMajorPrincipalAxis = true) const¶

    Compute the miss distance and combined position uncertainty in the rotated encounter frame.

    The rotated encounter frame is the encounter frame rotated about its z-axis, so that its x-axis and y-axis are along the principal axes of the combined position covariance projected onto the encounter plane:

    • If xAlongMajorPrincipalAxis is true, the x-axis is along the major principal axis and the y-axis along the minor principal axis.

    • If xAlongMajorPrincipalAxis is false, the x-axis is along the minor principal axis and the y-axis along the major principal axis.

    Raises an Undefined error if the encounter frame is null, or if a state has no position covariance.

    CloseApproach closeApproach = { ... } ;
Shared<const Frame> encounterFrameSPtr = closeApproach.computeEncounterFrame() ;
CloseApproach::RotatedEncounterFrameParameters parameters =
    closeApproach.computeRotatedEncounterFrameParameters(encounterFrameSPtr) ;
CloseApproach::RotatedEncounterFrameParameters parameters =
    closeApproach.computeRotatedEncounterFrameParameters(encounterFrameSPtr, false) ;
    Parameters:

    • anEncounterFrameSPtr -- An encounter frame, whose x-y plane is the encounter plane (see computeEncounterFrame)

    • xAlongMajorPrincipalAxis -- Whether to align the x-axis along the major principal axis (and the y-axis along the minor principal axis), or along the minor principal axis (and the y-axis along the major principal axis). Defaults to true

    Returns:

    The rotated encounter frame parameters
