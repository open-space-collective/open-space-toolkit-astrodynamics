    Class ostk::astrodynamics::uncertainty::Covariance¶

    class Covariance¶

    Covariance matrix at a given instant in time.

    Represents the covariance of an object's state at a specific instant, expressed in a given reference frame. The contents of the matrix are identified an ordered set of coordinate subsets.

    Public Functions

    Covariance(const Instant &anInstant, const MatrixXd &aCoordinates, const Shared<const Frame> &aFrameSPtr, const Array<Shared<const CoordinateSubset>> &aCoordinateSubsetsArray)¶

    Constructor. This constructor makes a new Coordinates Broker under the hood for every Covariance. 

    Covariance covariance = {
    Instant::DateTime(DateTime(2020, 1, 1, 0, 0, 0), Scale::UTC),
    aCoordinates,
    Frame::GCRF(),
    { CartesianPosition::Default(), CartesianVelocity::Default() }
} ;

    • aCoordinates -- The coordinates at the instant in International System of Units

    Throws:

    MahalanobisDistanceAnalysis computeMahalanobisDistanceAnalysis(const VectorXd &aResiduals) const¶

    Compute the Mahalanobis distance analysis of residuals with respect to the Covariance.

    The squared Mahalanobis distance is d² = rᵀ P⁻¹ r, where r are the residuals and P the Covariance coordinates. The p-value is the survival function of the chi-squared distribution with as many degrees of freedom as the Covariance size, evaluated at d².

    https://en.wikipedia.org/wiki/Mahalanobis_distance

    Parameters:

    aResiduals -- The residuals, expressed in the Covariance frame and ordered as its coordinate subsets

    Throws:

    ostk::core::error::runtime::Wrong -- If the residuals size does not match the Covariance size, or if the Covariance is empty or not positive definite

    Returns:

    The Mahalanobis distance analysis
