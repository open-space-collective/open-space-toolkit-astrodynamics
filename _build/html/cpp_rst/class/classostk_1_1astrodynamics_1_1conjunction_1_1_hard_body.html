    class HardBody¶

    Hard body (abstract).

    Physical extent of an object in conjunction analysis, from which a cross section can be calculated (see calculateCrossSectionAt).

    Subclassed by ostk::astrodynamics::conjunction::hardbody::Custom, ostk::astrodynamics::conjunction::hardbody::Spherical

    Destructor.

    virtual CrossSection calculateCrossSectionAt(const State &aState, const Shared<const Frame> &aFrameSPtr) const = 0¶

    Calculate the cross section of the hard body at a given state.

    The hard body is projected along the Z axis of the given frame onto its X-Y plane. Only the frame orientation is used: the cross section is always relative to the object position. Use the encounter frame (see CloseApproach::computeEncounterFrame, whose Z axis is the relative velocity) to project onto the encounter plane.

    Shared<const Frame> encounterFrame = closeApproach.computeEncounterFrame() ;
HardBody::CrossSection crossSection = hardBody.calculateCrossSectionAt(state, encounterFrame) ;
    Parameters:

    • aState -- A state of the object

    • aFrameSPtr -- A frame whose axes define the projection

    Returns:

    The cross section

    class CrossSection¶

    Cross section of a hard body, i.e. its projection onto a plane.

    A convex hull (convex polygon) dilated by a radius, i.e. all the points lying within the radius of the polygon. Coordinates are in meters, relative to the object position: they need no translation.

    The convex hull vertices must be:

    • Sorted clockwise, consistently with ostk::mathematics::geometry::d2::object::Polygon (any vertex first)

    • Not closed: the first vertex is not repeated at the end

    • Vertices of the polygon only: no duplicate, collinear or interior points

    One or two vertices are also allowed (point or segment).

    // Circle of radius 1.0 m
HardBody::CrossSection circle = { Array<Point>({ { 0.0, 0.0 } }), 1.0 } ;

// Square of side 1.0 m
HardBody::CrossSection square = {
    Array<Point>({ { 0.5, 0.5 }, { 0.5, -0.5 }, { -0.5, -0.5 }, { -0.5, 0.5 } }), 0.0
} ;

// Stadium: segment of length 2.0 m dilated by a radius of 0.5 m (total size 3.0 m x 1.0 m)
HardBody::CrossSection stadium = { Array<Point>({ { -1.0, 0.0 }, { 1.0, 0.0 } }), 0.5 } ;

    double getEnclosingRadius() const¶

    Get the enclosing radius of the cross section.

    Radius of the smallest circle centered on the object position enclosing the cross section: the distance to the farthest convex hull vertex, plus the radius. Raises an Undefined error if the convex hull is empty.

    Returns:

    The enclosing radius [m]

    static CrossSection combine(const CrossSection &aCrossSection, const CrossSection &anotherCrossSection)¶

    Combine two cross sections into their Minkowski sum.

    The convex hulls are Minkowski summed and the radii added, e.g. to obtain the combined cross section of the two objects of a close approach. Raises an Undefined error if either convex hull is empty.

    // Square of side 1.0 m with corners rounded by 1.0 m
HardBody::CrossSection combinedCrossSection = HardBody::CrossSection::combine(circle, square) ;
