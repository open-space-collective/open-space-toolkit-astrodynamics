    class PointingTargetGenerator(self, pointing_profile_generator_in_eci: collections.abc.Callable[[ostk.astrodynamics.trajectory.State], numpy.ndarray[dtype=float64, shape=(3), order='C']], direction_in_body_frame: numpy.ndarray[dtype=float64, shape=(3), order='C'])¶

    Bases: PointingTarget

    Represents a pointing constraint of one axis of the spacecraft towards a user defined pointing vector generator. Unlike the pre-defined target types, the target is fully user defined: the pointing vector is generated at each timestep by a function that returns a vector in the ECI frame (does not need to be known beforehand).

    Constructor.

    Parameters:

    • pointing_profile_generator_in_eci (Callable[[State], np.ndarray]) -- The function that generates the pointing vector in the ECI frame from the state at a given instant.

    • direction_in_body_frame (Vector3d) -- The (unit) vector in the spacecraft's body frame to point relative to the target - can be a basis vector (i.e. [1, 0, 0] for the X axis), or a custom vector (i.e. [0.70, -0.15, 0.69] for an arbitrary axis).

    class TabulatedPointingTarget(self, pointing_profile_in_eci: collections.abc.Sequence[tuple[ostk.physics.time.Instant, numpy.ndarray[dtype=float64, shape=(3), order='C']]], direction_in_body_frame: numpy.ndarray[dtype=float64, shape=(3), order='C'], interpolation_type: ostk.mathematics.curve_fitting.Interpolator.Type = Interpolator.Type.BarycentricRational)¶

    Bases: PointingTarget

    Represents a pointing constraint of one axis of the spacecraft along a user defined, tabulated pointing profile in the ECI frame. Unlike the pre-defined target types, the target is fully user defined: the profile is provided up front (must be known beforehand) and interpolated at each instant.

    Constructor.

    Parameters:

    • pointing_profile_in_eci (list[Tuple[Instant, Vector3d]]) -- The profile of pointing vectors in the ECI frame.

    • direction_in_body_frame (Vector3d) -- The (unit) vector in the spacecraft's body frame to point relative to the target - can be a basis vector (i.e. [1, 0, 0] for the X axis), or a custom vector (i.e. [0.70, -0.15, 0.69] for an arbitrary axis).

    • interpolation_type (Interpolator.Type, optional) -- The type of interpolation to use. Defaults to Interpolator.Type.BarycentricRational.
